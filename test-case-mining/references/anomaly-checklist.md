# Anomaly Checklist

Scout 主表：从代码异味反推"该写但没写"的测试假设。每命中一个异味，输出 `严重度 / 位置 / 异味 / 怀疑 bug / 推荐测试`。

异味只是**假设来源**，不是 bug 定论。最终结论由测试证伪或证实。

## 1. 空值与可选

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 直接解引用 `*ptr` / `obj.field` 无 nil 判定 | 空对象 panic / NPE | 传入 nil / None / undefined |
| `Optional.get()` / `unwrap()` 无判定 | 空值崩溃 | 测空容器 |
| 默认值散落各处，无统一来源 | 配置缺失时行为分叉 | 删除该字段 / 设为零值 |

## 2. 时间与时区

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 直接 `time.Now()` / `Date.now()` / `LocalDateTime.now()` | 跨天 / 跨时区结果不稳，难复现 | 注入时钟，测 23:59:59 → 00:00:00 |
| 硬编码 `Asia/Shanghai` 或本地时区 | DST、跨时区用户错误 | 切换 UTC / 不同时区 |
| 浮点秒做时间差 | 精度丢失、负数 | 测 1ms 级、跨午夜 |

## 3. 数值与精度

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 浮点用 `==` | 精度误判 | 接近相等但不严格相等 |
| `int` 处理金额 / 数量 | 溢出、精度 | 极大值、负数 |
| 除法无 0 判定 | DivByZero | 分母 0、极小数 |
| `len() - 1` / `i + 1` 索引 | 越界、空集合崩溃 | 空、单元素、首尾 |

## 4. 字符串与编码

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 按字节切片处理多字节字符 | 中文 / emoji 截断、乱码 | 含 emoji、CJK、半个字符 |
| `toLowerCase()` 无 locale | 土耳其语 I 问题 | locale = `tr-TR` |
| 直接拼 SQL / shell / path | 注入、路径穿越 | `'; DROP--`、`../etc/passwd` |
| 正则贪婪 / 无锚点 | 性能退化、误匹配 | 长输入、ReDoS 串 |

## 5. 资源与生命周期

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 文件 / 连接 / channel 未 `defer close` 或 `try-with-resources` | 句柄泄漏 | 高频调用 N 次后查计数 |
| goroutine / 协程启动后无退出路径 | 泄漏、堆积 | 取消 ctx 后断言协程退出 |
| 全局缓存无淘汰 | 内存膨胀 | 大量不同 key 后断言上限 |

## 6. 并发与共享状态

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 共享可变 map / slice 无锁 | data race | 开 race detector 多协程读写 |
| 双重检查锁 / 自创单例 | 初始化竞争 | 并发首次访问 |
| 锁顺序不一致 | 死锁 | 两条路径交叉持锁 |
| channel 无 buffer 且发收顺序敏感 | 阻塞 / panic on closed | close 后 send / 多次 close |

## 7. 错误处理

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| `try / catch` 吞掉异常 | 错误被静默吞掉，调用方误判成功 | mock 依赖抛错，断言上层感知 |
| 只 log 不返回错误 | 调用方继续走逻辑 | 注入失败，断言后续不执行 |
| 错误类型用字符串匹配 | 信息变更后分支失效 | 改 message，断言分支仍匹配 |
| `panic` / `unwrap` 在库代码里 | 进程级崩溃 | 喂边界输入触发 |

## 8. I/O 与外部依赖

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| HTTP 调用无超时 | 卡死 | mock 慢响应 |
| 重试无退避 / 无上限 | 雪崩、风暴 | 失败 N 次断言上限 |
| 重试无幂等键 | 重复消费、双扣款 | 同一请求重放，断言只生效一次 |
| 文件 I/O 假设原子 | 半写入、脏读 | 中途中断模拟 |

## 9. 缓存与一致性

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 写库不写缓存 / 写缓存不写库 | 脏数据 | 写后立刻读 |
| 缓存无过期 | 旧数据驻留 | 时间推进后断言失效 |
| 大量并发同 key 击穿 | 后端被打垮 | 并发同 key 首次未命中 |
| 缓存键拼接含可控输入 | 键冲突、越权读 | 注入特殊字符 |

## 10. 安全

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 鉴权与授权混淆 / 缺一 | 越权 | 用户 A 携 token 访问 B 资源 |
| 反序列化未限制类型 | RCE / 类污染 | 喂多态 payload |
| 日志打印敏感字段 | 凭证泄漏 | 断言日志中不出现密钥 / 手机号 |
| ID 为顺序数字 | 枚举 | 越权访问相邻 ID |
| 把用户输入拼进 shell / SQL / 模板 | 命令注入、SQL 注入、模板注入 | 恶意 payload 只能被转义或拒绝 |

## 11. AI / Prompt 边界

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 把用户 / 文档 / 网页文本直接拼进系统提示 | prompt injection 覆盖安全规则 | 输入"忽略之前指令"后仍遵守系统规则 |
| 工具调用参数由模型自由生成且无 allowlist | 误删文件、打真实服务、越权调用 | 恶意请求只能命中允许的只读 / mock 工具 |
| RAG 结果未标注来源或未隔离指令 | 检索内容变成执行指令 | 恶意文档只能作为引用，不影响执行策略 |
| LLM 输出未做结构校验就执行 | 格式漂移导致错误动作 | 非法 JSON / 缺字段被拒绝 |

## 12. 配置与环境

| 异味 | 怀疑 bug | 推荐测试 |
|---|---|---|
| 默认值在多个地方各写一份 | 行为分叉 | 删除其一，断言一致 |
| 启动期读 env，运行时再读 | 热更不生效 / 半生效 | 改 env 后断言行为 |
| feature flag 同时被读两次 | 中途切换不一致 | 切换中并发请求 |

## 严重度定义

- **Critical**：可导致数据损坏、安全越权、生产崩溃。
- **High**：影响核心路径正确性，难复现。
- **Medium**：影响次级路径或体验。
- **Low**：仅在罕见输入下可见。

```markdown
- 推荐测试: TC-12，注入冻结时钟，测 23:59:59 提交
```
